# 版式编辑与字体使用

## 编辑操作

- 拖动、缩放时先在本地预览，松开后记录一次修改。支持撤销与重做。
- Shift 点击多选，空白处拖动框选；组合后按整体移动、缩放、对齐。Alt 点击可选组内元素。
- 工具栏支持对齐、等间距分布、组合、取消组合和吸附。Alt 拖动临时关闭吸附。
- Ctrl+C / V / D 复制、粘贴、复制一份；Ctrl+G 组合，Ctrl+Shift+G 取消组合；方向键微调。
- Ctrl+Z 撤销，Ctrl+Shift+Z 或 Ctrl+Y 重做。空格或鼠标中键拖动画布；Ctrl+滚轮缩放；适应画布按容器计算倍率。

## 图片与检查

双击图片进入裁切，拖动调整焦点，使用缩放按钮调整范围。选择“仅当前卡牌”时保存单卡覆盖，不改变共享版式和其他卡牌。

多卡预览每页展示 12 张，可定位长文本。全牌组检查会检测文字溢出、缺失图片或图标、元素超出裁切范围；点击结果定位对应卡牌和元素。

## 字体库

侧栏打开“字体库”，上传 TTF、OTF、WOFF、WOFF2，或包含这些文件的 ZIP。ZIP 内其他文件会忽略；一次最多 64 个字体、总计 128 MB。上传时校验文件头与浏览器字体解析结果。

可预览字体、设为项目新建文字的默认字体，或应用到项目现有文字。单个文字也可在版式属性中选择字体。字体加载完成后才进行预览和导出；缺失或加载失败会显示错误。

字体作为项目素材存储。项目 JSON 本身不嵌入字体二进制，迁移项目时需要同时迁移素材文件。

## Agent 调用

应用内 Agent 使用 `font.list` 查询实际可用字体，再用 `font.set` 设置。参数为 `font`、可选 `deck`、`side`（front/back/both）、`element`、`setDefault`。指定元素时只修改该文字；未指定牌组时作用于项目全部文字。

例如：“查询项目字体，把角色牌组正面的标题改为我上传的 ArialBold，其他文字保持不变。”Agent 应先查询字体和目标元素，再用返回的真实 key 设置。

外部 MCP 提供 `list_fonts` 和 `set_font`，使用对应的项目、牌组与元素 ID。更新后重启后端/MCP 服务以加载新增工具。

## 行内富文本

文字属性开启富文本后，支持 `**粗体**`、`*斜体*`、`[color=#dc2626]文字[/color]`、`[size=36]文字[/size]`、`[icon:图标ID]`、`[image:素材ID]`。可通过图标或图片按钮插入真实引用；绑定字段内也可包含这些标记。

预览、溢出检查、打印和导出共享文字布局逻辑。SVG 素材先统一转为位图，保证主线程预览与 Worker 导出一致。

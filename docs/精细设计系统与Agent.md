# 精细设计系统与 Agent

## 入口

版式编辑器工具栏打开“设计系统”。先选择图层，再设置样式、组件、精确坐标、约束或视觉效果。工具栏另有可调间距网格、对比基线与“检查全套”。项目所有设置沿用本地保存、同步和撤销/重做。

## 共享样式与精确排版

共享样式保存字体、颜色、描边、间距和效果。可以从所选创建样式，应用到其他元素，修改后同步到全项目。面板在操作前显示绑定图层、牌组及局部覆盖数量。

手动编辑关联元素会生成局部覆盖，共享更新保留这些属性。“重置局部覆盖”重新跟随样式；“解除样式关联”保留当前外观。锁定图层跳过共享样式同步，解锁后可重新应用。

“精确排版”支持 mm / px 输入与四则运算，例如 `(20-4)/2`。换算依据当前版式的物理尺寸，不执行任意代码。字号仍为版式 px；实际印刷点数取决于物理尺寸与像素尺寸。

## 组件与实例

费用徽章、攻防条、稀有度标识等可保存为组件并插入实例。实例保存主组件关联和稳定图层 ID，支持字段绑定及局部覆盖。

- “用所选更新主组件并同步”将所选结构更新为主组件，并更新所有实例；先检查面板影响范围。
- 同步默认保留局部覆盖；“重置所有实例覆盖”会放弃该组件全部实例的局部改动。
- 解除实例关联保留当前图层；组件目前为单级平面结构，不提供嵌套组件或变体系统。
- 跨牌组插入前，目标牌组需要存在组件所用的相同字段 ID。
- 原始组件来源图层与新实例分开；保存组件后需要插入实例才建立联动关系。

## 锚点与自动布局

锚点支持左/右/居中/拉伸、上/下/居中/拉伸。改变画布大小后，根据保存的边距重新计算位置。

自动布局支持所选元素横向或纵向排列、间距、内边距及纵向交叉对齐。每个元素只能归属一个流式布局。自动布局成员位置由布局管理，解除后再手动拖动；解除时保留当前静态排列坐标。

文字区可以按内容扩展到最大高度，也可指定一张插图优先缩减高度并设置最低高度。达到限制后再按已有自动字号设置处理，仍放不下会报告溢出。该计算按卡牌数据执行，不改写共享版式或卡牌字段。

参考线仅用于编辑辅助，不会出现在导出图像。网格间距可调；启用吸附且显示网格时可按网格拖动，Alt 临时绕过吸附。

## 文字与视觉

- 文本内边距、段后距、首行缩进。
- 行内图标大小倍率与垂直偏移。
- 静态文本富文本选区工具：加粗、斜体、颜色、字号；底层仍使用可编辑标记。
- 项目规则片段：保存选中文字或全文，再插入到其他静态文本；绑定字段仍在卡牌数据中编辑。
- 图片椭圆蒙版、圆角和自定义 SVG path 裁切；路径使用 0–100 坐标，当前不含钢笔节点编辑器。
- 文字/形状线性渐变、阴影；图片可作为纹理层，使用透明度与 multiply/screen/overlay 混合。

预览、打印、导出共享渲染与布局解析代码。无需把文字和图标烘焙为整张不可编辑图片。

## 批量预检与对比

“检查全套”按每张卡实际内容检测：溢出、字号低于 6pt、自动缩字超过 25%、图片有效分辨率低于 150 DPI、缺失图片/图标、低对比（纯色估算）、缺失字段/样式/组件与失效自动布局引用。

低分辨率按图片裁切放大比例与牌面物理尺寸计算。字体加载失败会报告；当前不做完整字形覆盖分析，缺字、替代字体、复杂背景对比仍需人工校对。预检不代替印厂打样或 CMYK 色彩管理。

点击“记录对比基线”，修改后点击“查看前后对比”。两侧使用当前同一卡牌数据，比较版式差异；基线仅在当前编辑会话中保留。

## 内置 Agent

新增工具：

- `design.catalog {}`：查看样式、组件、规则片段、自动布局、版本和影响范围。
- `design.execute {deck,side,operation,args}`：执行样式、组件、锚点、自动布局、文字扩展、参考线、规则片段和精确坐标操作。
- `design.preflight {deck,side}`：加载素材后检查整组卡牌，返回问题卡牌与图层 ID。

效果属性也可使用 `element.update` 修改。重置样式或组件覆盖需用户授权；新增样式、组件、实例和规则片段接入现有重复执行保护。

示例：

```json
{"tool":"design.execute","args":{"deck":"真实牌组ID","side":"front","operation":"element.precise","args":{"ids":["真实图层ID"],"x":"10+2","unit":"mm"}}}
```

```json
{"tool":"design.execute","args":{"deck":"真实牌组ID","side":"front","operation":"layout.anchor","args":{"ids":["真实费用图层ID"],"horizontal":"right","vertical":"top"}}}
```

可直接提出：“查询项目设计系统，将标题使用统一样式；费用组件保持右侧边距；规则不足时先减少插图高度；最后检查整个牌组。”Agent 应先读取真实 ID、确认影响范围，再执行并预检。

这些新设计工具面向应用内 Agent；外部 MCP 仍可通过已有版式接口编辑相同 JSON 数据，尚未增加独立的外部设计系统工具。

## 验证

自动测试涵盖共享样式覆盖、稳定实例 ID、组件重置、物理单位算式、锚点、自动布局、文字扩展、段距和行内图标、自定义模板引用重映射。浏览器验证共享样式/局部覆盖、组件插入、毫米算式、渐变阴影、前后对比和 Agent 目录/自动布局/预检。

主线程与 Worker 的渐变、阴影、自定义图片蒙版、富文本测试比较了 100,800 个像素，差异为 0。实际图片、字体资源仍需随项目迁移。

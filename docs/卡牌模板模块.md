# 卡牌模板模块

## 模板目录

编辑器工具栏“模板库”提供 10 类原创、图层可编辑的通用版式：角色/单位、法术/行动、装备/道具、事件/遭遇、资源/能量、任务/目标、地点/建筑、规则/参考、数字/花色、叙事/塔罗。

内置羊皮纸、深空、简洁三套配色，支持已有尺寸预设。新建叙事/塔罗默认采用纵长尺寸；应用现有牌组默认保留其尺寸。模板只提供信息结构与基础视觉，不捆绑插图或商用游戏的边框资产。

## 使用

- 选择模板后查看画布预览，可切换尺寸、配色和应用面。
- 默认新建空牌组，不改变原牌组；卡牌数据可随后填写或由 Agent 生成。
- 应用到当前牌组前需确认替换范围。只替换选择的版式面，卡牌和已有字段保留，可撤销。
- 模板字段按兼容类型、真实 ID、名称与常用别名匹配；缺失时新增。多个候选不随意选择，可手动映射。
- 模板中插图、名称、描述、费用、数值保持字段绑定；空白插图框等待上传素材。模板预览使用示例值，不会写入实际卡牌。
- “将当前牌组保存为项目模板”保存正背面、字段与图层，存于项目 settings.cardTemplates，随项目内容保存。字体和图片仍依赖项目素材，不嵌入模板本体。

## 内置 Agent

| 工具 | 用途 |
| --- | --- |
| template.list | 查询内置及本项目模板，支持 query 搜索 |
| template.inspect | 只读查看模板版式、绑定关系和新增字段 |
| template.create | 用模板新建空牌组 |
| template.apply | 确认后替换现有牌组指定面版式 |
| template.save | 把当前牌组保存为项目模板 |

推荐自然语言：“查询角色模板，预览简洁配色，然后新建一个角色牌组。”或“预览 unit 模板应用到角色牌组的效果，将 description 映射到规则字段，只替换正面，保留背面。”

调用示例：

```json
{"tool":"template.inspect","args":{"template":"unit","deck":"真实牌组ID","side":"front","theme":"minimal","mapping":{"description":"真实规则字段ID"}}}
```

template.apply 被标记为替换操作，需要用户授权；template.create/save 使用现有防重放机制。项目模板新应用时会重建图层/组 ID，并重映射字段绑定、文本内字段引用、显示条件和数量展开字段。当前模板接口面向应用内 Agent；外部 MCP 仍可通过既有版式接口编辑，未新增外部模板工具。

## 模块与扩展

通用模块位于 frontend/src/lib/cardTemplates.ts，模板库界面与 Agent 共用实例化、字段匹配逻辑。新增内置模板可扩展目录和 pattern 构建分支；也可直接在项目中保存自定义模板。模板不包含嵌套组、脚本或不可编辑的整张牌面位图。

## 设计参考

只借鉴信息架构与印刷设计原则，未复制品牌边框、插画或下载他人模板文件：

- [Magic 官方卡牌构成说明](https://magic.wizards.com/en/news/feature/anatomy-magic-card-2006-10-21)：名称、费用、类型、规则与数值的信息分层。
- [Pokémon 官方规则书](https://assets.pokemon.com/assets/cms2/pdf/trading-card-game/rulebook/xy1-rulebook-en.pdf)：不同卡牌类型承载不同信息需求。
- [The Game Crafter 模板说明](https://help.thegamecrafter.com/article/39-templates)：安全区、出血和裁切误差。项目模板尺寸为裁切后尺寸；导出时仍需设置出血，并按实际印厂规格检查安全区。

## 验证

自动测试覆盖模板多配色/多尺寸生成、几何范围、字段映射、单面替换、卡牌数据保留、自定义模板复用与 Agent 操作。浏览器验证预览、新建、替换确认、保留另一面和项目模板保存。字体/插图的可移植性仍依赖素材随项目一起迁移。

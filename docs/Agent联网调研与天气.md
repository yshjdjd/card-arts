# Agent 通用联网与调研

天气问题只是通用搜索的测试用例；当前没有专用天气工具或天气 API。

- `web.search {query,maxResults?}`：通用搜索，返回标题、网址、摘要。
- `web.fetch {url,offset?,limit?,maxChars?}`：读取已知网址的静态文本正文。
- `web.research {query,maxPages?}`：搜索后读取多个来源，区分成功、部分失败和失败；继续检索可补充来源。

在上下文启用联网，选择搜索通道，使用“检测搜索连接”。检测必须调用所选搜索引擎，其他专用 API 能访问不代表搜索可用。DuckDuckGo 可能超时或要求验证；可以配置已有 Tavily、Brave、Serper 通道及其对应 Key。维基百科仅适合百科信息，不代表具备实时新闻或天气检索能力。

天气、新闻、价格等实时问题，均应搜索可靠来源、抓取正文并核对地点和更新时间；抓不到要明确说明，不能凭记忆编造。网页需要 JavaScript、验证码或登录时，当前静态读取可能失败。

后端代理可用 CARDARTS_HTTP_PROXY、HTTPS_PROXY、HTTP_PROXY 配置，修改后重启后端。搜索仍失败时，先解决搜索通道与后端网络问题，不能用专用接口的成功代替通用联网验收。

# 在版式中编辑卡牌数据

## 使用方式

版式编辑器工具栏可以选择当前卡牌，或直接新建卡牌。双击画布上的绑定元素，即可编辑当前卡牌对应字段。

- 绑定文字：编辑名称、规则、费用等字段，输入立即反映到画布。
- 图片字段：为当前卡牌选择素材，并可进入“调整此卡裁切”。
- 数字、选项、布尔、颜色：显示对应控件。
- 形状颜色或文字中引用 `{字段ID}` 时也可双击编辑；多个引用会提供字段选择。
- 静态、未绑定元素仍在共享版式属性中编辑，不会自动改为字段。

右侧新增“当前卡牌数据”，可展开所有字段进行编辑。同一字段在版式中出现多次时，会同步显示新值。富文本字段提供选区加粗、斜体、颜色和字号按钮，以及项目规则片段。

## 修改范围

| 操作 | 范围 |
| --- | --- |
| 当前卡牌字段值 | 仅当前卡牌 |
| 此卡图片裁切 | 当前卡牌覆盖 |
| 位置、字体、布局、组件等属性 | 共享牌组版式 |
| “此版式按富文本显示” | 当前面所有绑定该字段的文字元素，影响所有卡牌 |

面板和浮层均标明作用范围。修改卡牌数据不会改变字段定义，也不会把数据写成版式里的静态文字。

## 保存与撤销

输入先进入按项目、牌组、卡牌隔离的草稿，实时预览，停顿约 600ms 后合并保存。保存只提交变更字段，不覆盖其他字段或其他卡牌。

中文输入期间暂停保存；失焦、点击“保存并完成”或切换卡牌时保存。切换牌组和正背面前也会等待保存。保存失败或输入尚未完成时会阻止切换，保留草稿并提供重试。

撤销/重做前先提交当前草稿，避免未保存输入覆盖历史结果。连续输入通常合并为一次历史操作；多次停顿产生多次保存属于正常行为。

同一应用运行期内切换页面会保留失败草稿，返回编辑器可继续重试。若目标卡牌或字段已删除，面板显示错误及草稿内容，可复制后丢弃。刷新/关闭前有未保存输入时会触发浏览器离开提醒；草稿未另存为跨重启恢复文件，只有已保存数据保证持久化。

## 验证

独立浏览器验证通过：双击编辑、预览即时更新、中文输入保护、切卡保存、两段输入生成两条历史、实际撤销/重做、数字/选项/布尔/颜色、富文本选区、单卡图片选择与裁切、存储失败保留和重试、空牌组创建卡牌。共享版式和另一张卡牌数据保持不变。

专项测试：在 frontend 目录执行 `npm run test:cardfields`。既有 Agent 仍通过 card.update 等工具操作同一份卡牌数据，无需转换或额外同步格式。

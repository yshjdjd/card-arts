# Agent 长会话与恢复

## 模型上下文面板

打开助手顶部“上下文”，可查看统一管理面板：

- 容量预算进度条、输出预留与安全余量。
- 系统规则、工程快照、任务记忆、知识包、文档、待办、工具定义及历史用量估算。
- “上次实际请求”展示最近主循环请求的消息与工具定义，不包含 API Key；它不是当前输入的实时预览。
- “更新下次请求预览”按当前输入、挂载资料与历史重新组装，显示预算移出的历史数量；不调用模型或执行工具。
- 服务商返回 usage 时展示真实输入/输出/总用量，否则显示未返回。
- “立即压缩历史”使用当前模型生成摘要，可取消；失败或截断不覆盖原摘要。压缩保留原始消息。
- “恢复使用原历史”清除摘要，下次重新按预算选取历史；不保证所有原文能一次放入模型窗口。
- 可设置自动压缩开关、历史触发阈值和固定约束。

分项 Token 仍是字符估算，按提示词段落归类，消息与编码开销会使合计存在小幅差异。进度条以配置的模型容量计算，请填写供应商实际容量。最近请求快照随删除或清空会话清理。

容量支持自动识别：模型设置点击“按模型自动识别”，再“拉取列表”可刷新接口元数据。优先级为手动覆盖、当前接口模型元数据、已核实的模型预设、未知模型 64K 回退。接口元数据按地址与精确模型 ID 隔离；切换模型或思考模式后重新解析有效模型。DeepSeek V4 Pro、V4 Flash、deepseek-flash 预设为 1,048,576（依据 2026-11-09 官方说明），代理部署可能更小，应以接口元数据或手动覆盖为准。

新默认自动压缩阈值为有效容量的 60%。已保存的阈值继续保留，可点击“按当前模型自动设置阈值”恢复动态阈值。已有手动容量同样不会被静默覆盖。输入/输出仍共享窗口，容量上限不等同于单次输出上限。

单次输出额度同样支持自动与手动。模型设置中点击“按模型与思考模式自动设置”：普通模式建议 32K、思考模式 64K、思考强度 max 为 128K，并按接口元数据输出上限与上下文容量约束。DeepSeek V4/Flash 官方预设输出上限 393,216，接口元数据优先；未知模型仍保守限制。设置页显示额度来源及实际发送值，面板输出预留与实际请求使用同一解析结果。摘要请求单独显式限制为 1,800，不因主任务自动额度而放大。

新配置默认自动，已有配置继续沿用旧手动值；输入数字或点击快捷额度进入手动模式。显式手动模式下切换思考开关不会静默改写额度。输出上限是允许生成的最大值，不是实际用量。

## 会话与任务记忆

每轮请求包含首次目标、近期要求、待办、执行状态和用户固定约束。在输入区点击“任务记忆 / 固定约束”可编辑长期要求。模型摘要可能遗漏细节，固定约束与真实工程读取结果仍须核对。

历史达到阈值时，使用当前模型发起一次不携带工具的摘要请求；保留近期完整轮次。摘要失败、被取消或输出截断时不替换旧历史。摘要面板可查看和清除摘要，原始消息不会因摘要而删除。

## 按需读取

- `conversation.search {query}`：搜索本会话原始正文，返回消息 ID。
- `conversation.readTurn {id,offset?}`：分页读取对应消息。
- `conversation.readResult {ref,offset?}`：分页读取长工具结果，每页最多 2400 字。

长工具结果先保存完整原文，再返回有限预览与引用。结果归档失败不会把已经完成的工程操作改记为失败。Token 数为估算，包含工具定义；不是模型服务的计费用量。

## 恢复与分支

工具交互检查点保存在本地 IndexedDB 独立事件表。后续发送时组装历史工具调用与结果；没有对应结果的调用不作为已完成调用重放。显式“继续”会复用已有操作记录，减少重复新增。

消息上的“从此处分支”复制截至该处的历史与结果引用；清除危险操作授权、旧摘要和待办。分支保留当前工程状态，**不会把卡牌工程回滚到该消息时的版本**。

取消会停止后续生成与尚未开始的动作，已经提交的修改保留；正在执行的外部操作是否停止取决于工具本身是否支持取消。进程恰好在修改提交后、记录保存前崩溃，仍可能出现结果未知，需要先检查工程，不能承诺严格一次执行。

## 工程版本检查

每项工具执行前检查项目本地版本。发现冲突后，写操作持续阻止，直到成功读取最新项目资料；读取聊天历史不能解除冲突。该机制不替代数据库原子并发控制，也不能防止外部 MCP 服务内部的并发修改。

## 数据范围

消息、事件、摘要和长结果目前保存在浏览器本地；尚无跨设备会话同步。删除或清空会话会清理对应事件与结果。首次刷新遇到 IndexedDB 升级阻塞时，关闭其他旧版页面后重开。

回归测试：在 frontend 目录执行 `npm run test:agent`；构建执行 `npm run build`。
